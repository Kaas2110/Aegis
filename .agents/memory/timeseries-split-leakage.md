---
name: Time-series/series split rules
description: Правила сплита и фичей для ML на матчах/сериях без утечек
---
Правило: train/calib/test сплит — только по границам групп (серия целиком в одном сплите) и по времени; рейтинговые фичи брать из snapshot-таблицы на дату события (fallback — ранний снапшот), не из текущих значений.
**Why:** сплит по сэмплам клал карты одной серии в train и test одновременно, а текущие рейтинги тащили «будущее» — метрики были завышены.
**How to apply:** в любом новом train-скрипте группировать по series/match id перед сплитом; для as-of фичей использовать team_rating_snapshots.
