---
name: Порядок записей в docs/changelog.md
description: Куда дописывать новые записи changelog
---

Правило: новые записи в `docs/changelog.md` дописывать В КОНЕЦ файла.

**Why:** шапка файла заявляет «свежее — сверху», но фактически записи 2026-07 лежат в конце, а верх файла — май 2026. Вставка в начало ломает реальную хронологию.

**How to apply:** `cat >> docs/changelog.md` с новой секцией `## YYYY-MM-DD — …`. Не переставлять существующие секции без явной просьбы пользователя.
