---
name: Формы ответов эндпоинтов матчей
description: Нестандартные обёртки ответов /api/matches/* и как их разворачивать
---

Правило: перед матчингом/агрегацией live-матчей всегда разворачивать обёртку источников.

- `GET /api/matches/live` → `{ sources: [{ source: 'opendota'|'stratz'|'pandascore', data: [...] }] }` — НЕ плоский массив.
- `GET /api/matches/upcoming` → `{ noData: boolean, data: [...] }`.

**Why:** баг F7 (Bovada matched=0) случился именно потому, что потребитель ожидал плоский массив и молча получал 0 матчей; аудит 2026-07 повторно подтвердил форму.

**How to apply:** любой новый потребитель этих эндпоинтов (matcher, e2e, admin-web) сперва делает `sources.flatMap(s => s.data)` / `resp.data`. Пустой результат при работающих upstream'ах — почти всегда непонятая обёртка, а не отсутствие данных.
