2. HISTORY AND SOURCE PROOF
boundedRetainedHistory resolves each target map from retained original versions,
including null updates, identity conflicts, retractions and actual clock horizons.
The retainedReferenceCorpus v2 materializer/reader re-reads all required committed
dependencies and mints private source handles. Producer AND consumer dispatch the
v2 handle through its private reader; changing/copying JSON is not authority.
Original generation/version identity remains in the descriptor. Late identity t1
does not move the original complete-draft t0. Current-map finals remain excluded;
unrelated historical meta population is retained. V1 dense limits/readers remain.

The new exact scalar statistics utility uses bounded descriptor batches, numeric
map-ID arithmetic, a separate sample-SD pass and exact Float64 radix order
statistics. It is a reusable primitive, NOT an integrated replacement for every
historical relational, weighted, player/hero/role/opponent family calculation.
The heavy source case crosses64MiB in ORIGINAL retained bytes with fourteen padded
synthetic versions, actual producer and real writer reopen. It does not cross64MiB
of normalized history or reconcile a complete-year production archive.

compactHistoricalInputStore stores static PRE/SERIES_PRE/BETWEEN input bytes in
the same owned writer, commits the manifest last, rechecks each actual dependency
and binds requested mode/pins/minimumSupport. Journal append/reload requires its
private proof when historicalInputRef is supplied. Close-after-await fences prevent
minting new proofs after shutdown. This is byte/pin/support integrity only: caller
cutoff/validFrom metadata is not independently parsed target causality or proof of
original provider availability. These limitations stay false in the descriptors.

3. COMMON GENERATOR AND MEMORY OWNERSHIP
Compiler cache keys now bind actual normalized definitions, formula/policy and
names, rather than trusting a claimed schema hash or a shallow-frozen wrapper.
Current values and masks are checked/copied each time. Owned deep-frozen schemas,
normalized rows and projection plans have private identities and byte arena leases.
Active routes survive cache eviction/producer close. Compiler-minted schema and
vector leases let a sink borrow exact immutable data without trusting JSON copies.
The common producer now exposes bundle.release(), close(), resourceStatus() and
retainSchema(). Immutable history/draft/metadata caches are owned separately from
current rows. Partial generation failures release acquired rows/route owners.

Consumer execute retains bundles through awaited schema/trace/restore callbacks,
then releases in finally. Recognized continuations retain the actual opaque frozen
token, not a cloned token or unrelated byte reservation. A pending job separately
borrows the prior token before reentrant host calls, so a source barrier cannot
release its charge while that job still uses it. Slot replacement, barrier and
forget release their own owners; candidate/prior borrows survive bundle cleanup.
Continuation byte accounting is a conservative public-state/private-lead proxy,
not measured hidden heap. Upstream global definition pools and generation transient
allocations still need full ownership acceptance. A global16GiB supervisor is NOT
activated. Canonical cleanup is trusted nonthrowing; arbitrary throwing external
cleanup ports are not a newly accepted interface.

4. PERSISTENCE AND PERFORMANCE DECISIONS
Canonical hash output is unchanged; small string pieces are buffered before hash
updates, including surrogate-boundary handling. Compact wire manifests v3 split
top-level fields into bounded UTF8 chunks so shared dictionaries/vectors dedupe
across target headers. V2 manifests remain readable with their original bound.
The owned writer offers bounded readMany and advertises its configured aggregate
capacity. Every object/marker/hash is checked, and the root inventory is fenced at
both batch boundaries. Lower writer limits are negotiated, never silently raised.
The final review found one additional serial-only-wrapper defect: its fallback
launched several reads concurrently despite maxPendingOperations=1. It now awaits
each read in order. Actual multi-chunk owned-writer reload/verification covers this
case; the17-case corrective scope passed after fixing an awaited inspect assertion.
Compact schema reuse requires private compiler identity and verifies disk bytes
again. Prepared private schema/vector leases are captured before the first await;
each route is factored/persisted/released in turn. Vector cache charges include
schema dependencies. Encode/decode scratch is admitted from private actual wire
bounds plus the independent decoder structural preflight, rather than reserving
the maximum wire allowance for every small object.
