The main card always forecasts the whole match/series. Inside, outcomes and totals
belong to the selected map; previous-map viewing preserves its own heroes/results.
LIVE final totals add current observed score or elapsed seconds exactly once to
remaining outcomes. PRE excludes current selected heroes/live values; BETWEEN does
not reuse a stale prior current-map state or invent the next map draft/identity.
Series team1/team2 orientation is explicit; a map Radiant probability is not a
series team1 probability. These are contracts, not12trained models or13live feeds.

Generated definition ledger and remaining semantic gate
createGeneratedDefinitionLedger captures the exact supplied actual unified schemas,
source inventories, every distinct definition/source-inventory variant, ordered
occurrences, formula/version/units/missingness/scopes and metadata declarations.
Its hashes bind exact descriptors and helper inventories; a helper-source change
can create a different variant even when the primary descriptor bytes are equal.
verifyGeneratedDefinitionLedgerReceipt establishes byte consistency only. It does
not turn a self-consistent edited ledger into semantic authority. Rebuild from
exact immutable producer schemas when validating its actual semantic provenance.

summarizeGeneratedDefinitionDispositions is a compact view of that exact ledger:
all79families,14legacygroups and12targets/13modes remain present even when schemas
for some modes were not supplied. phaseSchemaObserved describes supplied schema
presence, not a source success rate. Family source profiles and metadata gaps are
summarized without expanding the definitions again. generatedVariantCount counts
source-bound variants, not independent samples, complete semantic migration or
currently known scalar operands. An empty schema set proves inventory only.

The code deliberately records missing policies instead of silently inventing them:
- exact_input_fields_not_declared, including an empty inputFields array;
- separate_event_time_policy_not_declared;
- separate_availability_time_policy_not_declared;
- historical_support_unit_not_declared;
- historical_population_policy_not_declared;
- role_policy_or_nonapplicability_not_declared;
- patch_policy_or_nonapplicability_not_declared.
Actual HIST descriptors declare windows/minimumSupport/formula/units but generally
lack exact inputFields, separate event/availability policies, supportUnit,
populationPolicy, rolePolicy and patchPolicy at definition level. DRAFT/SERIES
also lack several of these explicit declarations. LIVE often declares inputFields
and historyDefinitions, but some wrappers preserve empty arrays, and explicit
