Problem and decision
The projected-row coverage adapter already checked an actual private projected
row and computed complete ordered per-column support pages, but only summary and
page hashes were retained. That was not an inspectable per-feature artifact.

audit readPage(offset,limit<=200) interface, without a dense feature matrix.
The harness applies that adapter to its actual decoded RESTORED private vector,
then exports the resulting support pages. Original vector substitution is not used.

Pure exporter interface and limits
exportFeatureDataCoveragePages({audit,rowBinding,provenance,featureProvenance,
 writePinned,readPinned,resourceArena,shouldContinue,maxWallMs})
The injected writer takes {reference,bytes:Buffer,fileLabel}; the reader returns
actual Buffer bytes. Every artifact write is read back with exact byte length and
SHA256. Each gzip JSON page contains at most200 ordered columns,4MiB expanded,
16MiB encoded object maximum. Up to1500pages/300000columns are allowed; the final
per-row/mode index is bounded4MiB. Work is admitted under128MiB in the same arena,
released on every exit. shouldContinue must return exactlytrue; wall time is
finite and cannot exceed1200seconds. STOP after a write prevents a complete index.
Pages are decompressed under the4MiB limit and compared with their original exact
expanded bytes. Existing adapter fullColumnPagesSha256 is verified when supplied.

Indexes bind exact target/state mode, profile, actual schema/function/producer/
row-parameter/context/value/projection hashes and row-binding digest, plus every
ordered page pin and column-definition digest. Source/raw and feature-issuance
axes stay explicit. No opaque private capability is serialized. Full source
meaning remains referenced by the exact schema/function contracts; the audit's
bounded display names retain their full-name SHA and ordered column indexes.
The exporter itself does not certify an arbitrary callback as a private source.
If audit.descriptor is available, its entire canonical row-binding digest MUST
equal the supplied rowBinding; same-function/context-mismatched audits refuse.
The actual private projected profile/actualPrivateRowVerified summary requires
that descriptor. Generic audits without it are explicitly marked
not_provided_unverified_generic_audit and never gain source/private authority.

Separate persistent report directory
createCoverageReportDirectory requires explicit absolute directory and scopeRoot;
the destination must be a strict descendant of the allowed working root. Each
ancestor and file is checked as a plain nonsymlink directory/regular file. New
files are hash-named, written with wx and never overwritten or deleted. Known
existing files are exact-hash re-read, not trusted by filename alone. Unknown
entries, mismatched identities, foreign locks, larger/changed files or out-of-
scope paths refuse. A new owned .coverage-writer.lock prevents cooperating report
writers from overlapping; only that exact owned token/file is removed on close.
Existing foreign locks are never removed. This is not the native Windows journal
lease and does not claim an OS-wide supervisor/security isolation guarantee.
Owned lock identity and a bounded token read are checked before and after each
read/mutation/receipt and after initial inventory. Loss permanently poisons that
owner; it cannot continue with its old encoded-retention ledger. The final close
checks the identity/token again immediately before unlink and preserves changed
foreign locks. These lstat/open/token fences are cooperative checks, NOT atomic
native OS lease proof; an adversarial same-token race is not claimed solved.

One independent128MiB cumulative retained-encoded-file-byte cap includes ALL
report pages, indexes and the temporary lock, with25000file bound. This sums file
lengths; allocated NTFS sectors and filesystem overhead are NOT measured. It does not alter the journal's
separate256MiB root limit. Directory inventory ownership has a bounded32MiB arena
reservation; bounded read buffers have additional transient reservations.
Partial reports from failed/stopped exports remain; no completed exporter receipt
or full collection is accepted without successful readback. A written but not
accepted final index may remain after failure. Nothing is deleted automatically.
