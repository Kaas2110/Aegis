Metadata discovery
The stdlib-only Python script reads installed distribution metadata for exactly
LightGBM/CatBoost/XGBoost, plus Python version/platform and a UTC recording time.
It does not import those model libraries, install anything, call providers or
fit/score models. Exception text and local paths are not returned. A found
distribution is NOT verified native usability. Run it with the intended ML
Python environment; output from another interpreter cannot establish that
environment's installed distributions. No current versions are asserted until
root records its actual metadata-only receipt. Use isolated Python startup.
