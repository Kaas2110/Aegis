# Aegis — Бизнес-описание

> Документ для product / business stakeholders. Технические детали — в
> [`docs/architecture.md`](./architecture.md) и [`docs/technical-overview.md`](./technical-overview.md).

## 1. Что это и для кого

**Aegis** — мобильное приложение (Expo / React Native) с аналитикой
профессиональных матчей Dota 2. Целевая аудитория — русскоязычные
ставочники-любители Dota 2 (18+), которые принимают решения сами и хотят
вторую точку зрения от ML-модели вместо «чуйки» или статей-постфактум.

Мы **не букмекер** и **не принимаем ставки**. Мы:
- показываем live + upcoming матчи в один клик с командами и счётом серии;
- считаем вероятности по 15 рынкам ставок (победитель матча/карты,
  тоталы убийств / длительности, фора, точный счёт, первая кровь);
- сравниваем нашу вероятность с публичной линией букмекера (там, где она
  доступна) и подсвечиваем расхождение;
- алертом дёргаем пользователя, когда модель видит высокую уверенность.

## 2. Бизнес-сценарии (как пользователь работает)

### Сценарий A — «Сегодняшние матчи»
1. Пользователь открывает приложение → попадает на вкладку «Матчи».
2. Вверху — фильтры (live / прематч, формат BO1/3/5, минимальный
   коэффициент, минимальная уверенность).
3. Список карточек: команды, лого, счёт серии (для live), время старта
   (для прематч), наш прогноз победителя в %, и (если букмекер
   подключён) — лучший доступный коэффициент.
4. Тап по карточке → детальный экран матча.

### Сценарий B — «Детальный анализ матча»
Внутри матча:
- **Шапка** — счёт серии (для live), статус «ЛАЙВ N:NN» / «ПЕРЕРЫВ» / «ПРЕМАТЧ».
- **Победитель** — вероятности обеих команд (наша модель), коэффициент
  букмекера, расхождение в процентах (если есть бук).
- **Ladder тоталов убийств** — несколько линий (47.5, 50.5, 52.5...) с нашей
  вероятностью «больше/меньше». На live центрируется вокруг текущего темпа.
- **Длительность матча** — медианная оценка ± 50% интервал (квантильные
  модели LightGBM α=0.25 / 0.75).
- **Первая кровь** — вероятность каждой стороны.
- **Карты серии (Map 1/2/3)** — отдельные предсказания по каждой карте.
- **Драфт** — герои обеих команд (с лайва или прематча).
- **Глоссарий** — рядом с каждым показателем кнопка «?» с объяснением.

### Сценарий C — «Алерты»
Пользователь хочет получать уведомления, когда модель уверена в исходе:
1. Вкладка «Алерты» → переключатель «ВКЛ/ВЫКЛ» в шапке (глобально).
2. По дефолту — алерт срабатывает на любой матч/рынок при уверенности ≥ 70%
   (порог настраивается чипами 60..90% на вкладке «Правила»).
3. Можно создать кастомные правила: «только лайв», «только избранные команды»,
   «только тип рынка X», «уверенность ≥ Y%».
4. Сработавшие алерты копятся в списке «Сработавшие».

### Сценарий D — «Регистрация и профиль» *(добавлено 2026-05-15)*
1. Первый запуск → онбординг (возрастной gate 18+, дисклеймер, дефолтные фильтры).
2. После онбординга → экран входа: **Email + пароль**. Можно зарегистрироваться
   по email (минимум 6 символов) или войти, если аккаунт уже есть.
3. После успешного входа — токен (валиден 30 дней) сохраняется в памяти
   устройства; больше email не спрашивается.
4. На вкладке «Профиль» — карточка «Аккаунт» с email и кнопкой «Выйти».
5. Кнопка «Выйти» очищает локальный токен → при следующем заходе требуется
   ввод email повторно.

> Apple ID / Google Sign-In пока недоступны (требуют опубликованного
> приложения в сторах). Email-аутентификация — временное решение, чтобы
> мы видели, кто наш клиент, и могли впоследствии мигрировать аккаунты на
> Sign in with Apple / Google.

## 3. Бизнес-процессы (как работает «фабрика данных»)

### 3.1 Источники данных (внешние)

| Источник       | Что даёт                                          | Лимиты                    |
|---------------|--------------------------------------------------|---------------------------|
| OpenDota      | Pro matches, лайв-снимки, драфты, hero stats     | бесплатно, ~1 req / 1.1s  |
| Stratz        | Альтернатива OpenDota (драфты, hero matchups)    | бесплатно, 250 req/min    |
| PandaScore    | Upcoming матчи, running матчи, лиги              | бесплатно (free tier)     |
| Bovada (US)   | Букмекерские коэффициенты (winner, totals, FB)   | публично, без ключа       |
| 6 РФ буков    | (Fonbet, Лига Ставок, PARI, BetBoom, 1xStavka, Olimp.bet) | заблокированы с Replit-IP |

### 3.2 Поток данных (high-level)

```
[OpenDota / Stratz / PandaScore] ─┬─► api-server (Express)
[Bovada]                          │      │
                                  │      ├─► Postgres (исторические данные, модели)
                                  │      ├─► ml-service (LightGBM scoring)
                                  │      └─► withCache (30s live / 60s upcoming)
                                  │             │
                                  │             ▼
                                  │      Mobile (Expo) ─ live / upcoming + прогноз + алерты
                                  │
                                  └─► Admin web (React) ─ метрики, ретрейн, refresh-all
```

### 3.3 Жизненный цикл матча (бизнес-таймлайн)

| Фаза       | Что происходит                                                                |
|-----------|-------------------------------------------------------------------------------|
| **Прематч** | PandaScore видит матч за часы / дни. Прогноз: ELO + recent form + h2h + (если есть драфт) hero синергия / контрпики. |
| **Драфт**  | OpenDota / Stratz отдают picks/bans. Прогноз обновляется с учётом героев.    |
| **Лайв**   | LiveWorker каждые 60s опрашивает OD на ход матча: счёт убийств, башни, золото. Live-винер модель пересчитывает вероятность каждый снапшот. |
| **Перерыв между картами** | После конца карты в BO3/BO5 — ~1-5 мин до старта следующей. Карточка показывает «ПЕРЕРЫВ» (вместо устаревших данных). |
| **Конец матча** | OutcomeTracker фиксирует исход → пишет в `prematch_outcomes` (для будущего ретрейна). |

### 3.4 Перезапуск моделей (ML-цикл)

1. Раз в N часов (или вручную через админку) — `train:lightgbm` на свежих
   `pro_matches` → новые веса → атомарный swap (без даунтайма).
2. Метрики (test_acc, brier score, log loss) пишутся в БД.
3. Если новая модель хуже текущей — old остаётся, новая откладывается на проверку.
4. Live-винер модель ретренится отдельно на `live_snapshots × prematch_outcomes`.

### 3.5 Букмекеры — фоновый воркер

Каждые 3 минуты во время лайв-матчей (60 минут в idle / 30s после старта
ближайшего upcoming) BookmakerWorker опрашивает все доступные источники
параллельно. Результат — общий кэш, к которому мобилка ходит за прогретыми
данными без апстрим-задержек.

## 4. Текущее состояние (2026-07-17)

### Что работает в проде
- ✅ Live + upcoming матчи
- ✅ Bovada — единственный отвечающий букмекер с Replit-IP; 6 РФ-источников
  написаны и активируются автоматически при запуске с РФ-IP (ноут)
- ✅ Fuzzy-matching букмекерских событий с нашими матчами
- ✅ ML-модели: LightGBM v3 prematch + LR fallback + live-winner +
  series-mid модель (P серии по ходу BO3/BO5, acc 87.6%) +
  15 market-моделей (первая кровь, тоталы, квантили длительности) +
  4 live-totals модели (прогноз финальных тоталов из текущего снапшота)
- ✅ 15 рынков с предсказаниями, ladder-UI тоталов
- ✅ Алерты с настраиваемым порогом и глобальным переключателем
- ✅ Email-регистрация, локальный токен на 30 дней
- ✅ Рефералки: короткие ссылки `/r/{код}`, статистика кликов/регистраций,
  CSV-экспорт, промокод на регистрации, поле тарифа (free) под будущий Premium
- ✅ Админ-панель (admin-web): метрики, ретрейн, refresh-all, источники/рефералки
- ✅ Возрастной gate, дисклеймер «не советуем ставить»

### Известные ограничения (бизнес)
- ❌ 6 РФ букмекеров с Replit-IP не работают (геоблок / Cloudflare).
  Решается прокси-сервером в РФ — это инфраструктурный вопрос.
- ❌ Pinnacle требует guest API key (платный) — отложено.
- ❌ Apple/Google Sign-In — после публикации в сторе.
- ⚠️ Бэктест-вкладка скрыта (мало данных, разблокируется при ≥200 строк
  `prematch_outcomes`).

## 5. Юридические и этические рамки

- **18+ gate** на онбординге, без подтверждения возраста дальше не пускаем.
- **Дисклеймер** на онбординге и в нижней части настроек: «приложение не
  гарантирует результат, не размещает ставки, не является советом».
- **Не храним** платёжные данные. Email хранится hash'ированно через scrypt.
- Не интегрируем кошелёк / депозит / вывод — мы только аналитика.
