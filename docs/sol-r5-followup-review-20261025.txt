Decisions and implemented interfaces
1. Persistent artifact writer and OS lease
createPersistentArtifactWriter({directory,leaseProvider,shouldContinue,limits})
returns commit({kind,utf8,expectedSha256}), read(reference), inspect(),
listCommitted({kind}) and close(). Exact immutable references are {kind,sha256,bytes}.
Discovery returns bounded acknowledged journal order with commitSequence and root
generation. The Windows helper holds an actual OS byte-range lease; it starts only
through explicit factory configuration and stays in the owned technical job.
There is one serialized writer, durable reservation/acknowledgement journal,
root generation/fencing epochs, cumulative physical+reserved disk accounting and
marker-last visibility. Unknown/partial/corrupt files fail closed. Exact retries
resume only their own known reservation. No age/PID-based cleanup or lock takeover.
Object content is rechecked on dedupe/discovery; successful exposure rechecks STOP
and lease after IO. Same-instance retry now reconciles a published marker whose
acknowledgement was interrupted, before reporting success/discovery.
Default root256MiB/object16MiB/artifact10000 limits are unchanged small-scope
foundation bounds. They are not an archive storage capacity claim. Windows file
flushes are real; portable directory-fsync/power-loss guarantees remain qualified.

2. Retained reference corpus and target views
createRetainedReferenceCorpus/restoreRetainedReferenceCorpus mint private generation

4. Compact assets and opt-in journal

missing bitmap behind private handles, preserves ordered names/definitions/hash,
and exposes bounded leased pages. Null, zero and negative zero remain distinct.
Cache ownership and in-flight holds are separate; eviction does not uncharge an
active reader. Encoding, intake, decoded pages and retained text have their own
explicit arena estimates. These are engineering accounting, not measured heap.
Saturating DAG expansion checks precede recursive decode/hash. Encoding rejects
undersized work before materializing full vector/string tokens. Incremental source
factoring admission is independently reviewed in this block's final evidence.
compactFeatureJournal is a separate explicit factory over the owned writer/arena.
appendBundle uses actual common-producer bundles; loadTrace returns owned per-target

hashes and false training/serving/prediction flags. Exact phase/time bindings and
returned writer receipt equality are checked. Cached assets still reverify stored
chunks on reload. Manifest commits last after all schema/vector chunks.
A full rich test exposed the initial16MiB whole-object incompatibility. Persistence
now uses <=1MiB UTF8 shards and a final manifest, with explicit64MiB logical-wire
bound; writer's16MiB individual object cap stays unchanged. Synchronous codec output

ends, avoiding double reservation of maximum work during decode. OS/arena/root and
individual-object caps stay fixed; the new sharded logical-wire profile is explicit.
No features are trimmed to make a test pass.
The v1 default compiler/journal/read path is retained. This new adapter is not yet
