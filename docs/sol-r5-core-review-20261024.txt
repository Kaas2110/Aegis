PROBLEM / RESULT
Full queues used to copy/hash another large payload; repeated Steam clocks could
reject plausible later advancement; async diagnostic reads could report expired
state as current. Frozen historical source envelopes were rebuilt per live frame.
The new core addresses those contracts with early memory admission, one globally
serialized generation/commit per consumer, owned final read fences and private
compact history-source authority. Source-only diagnostic work; no model activation.
